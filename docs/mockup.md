# Mockup das telas

Mockup navegável das telas do Órbita (tema escuro, navegação em painel lateral), feito como protótipo clicável:

🔗 https://claude.ai/artifact/FxxPsECbrMQDnsogzNfMH7

> **Nota:** este link é privado — só abre para quem está logado na conta Claude da autora do projeto. Não é um link público de visualização.

## Telas incluídas

- **Lista de projetos + Detalhe do projeto** — painel fixo à esquerda com a lista (ordenável, com indicador de prioridade e barra de progresso), detalhe abre ao lado com prioridade, tarefas (checkbox + prazo individual), descrição, prazo, pomodoro e gráfico de progresso semanal.
- **Planeta** — tela do sistema de recompensa: nível, XP até o próximo nível, sequência de dias (streak) e histórico dos últimos 7 dias.

## Decisões de visual fechadas neste mockup

- Tema escuro como padrão (fundo quase preto, acento roxo/violeta)
- Navegação em painel (sem troca de tela cheia entre lista e detalhe)
- Indicador de recompensa discreto na barra superior, levando à tela do planeta
